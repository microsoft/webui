Deployment is framework-dependent, not self-contained. This directory includes
only the bootstrap loader, not the Windows App Runtime shared framework.
Install the matching-architecture Windows App Runtime 1.8 on destination
machines, as well as the WebView2 Runtime required by WebUI. The bootstrap DLL
does not install the shared runtime. No download or runtime installation is
performed by the WebUI build script.
